# Service Management

Sistema web de gerenciamento de ordens de serviço (OS) para empresas de assistência técnica.

## Sobre o projeto

O Service Management tem como objetivo simplificar o gerenciamento de clientes, equipamentos, atendimentos e ordens de serviço, oferecendo uma plataforma organizada, segura e preparada para atender múltiplas empresas.

O desenvolvimento começa com o segmento de assistência técnica de celulares. A arquitetura será preparada para permitir a expansão futura para outros segmentos, como oficinas automotivas.

## Funcionalidades planejadas

- Cadastro e gerenciamento de clientes.
- Abertura, edição e acompanhamento de ordens de serviço.
- Controle de status e histórico de alterações.
- Registro de diagnósticos, orçamentos e aprovações.
- Geração e versionamento de documentos PDF.
- Consulta pública e segura do andamento da OS.
- Controle de usuários, permissões e acesso por empresa.
- Registro de garantias e retornos de equipamentos.

## Tecnologias planejadas

- **Frontend:** Vue 3, TypeScript e Tailwind CSS.
- **Backend:** Node.js, TypeScript e Fastify.
- **Banco de dados:** PostgreSQL.
- **ORM e migrações:** Prisma.
- **Autenticação:** Supabase Auth.
- **Testes:** Vitest.
- **Versionamento:** Git e GitHub.

## Status do desenvolvimento

Em fase inicial de planejamento e definição de requisitos.

## Segurança

O sistema será desenvolvido considerando isolamento dos dados entre empresas, controle de permissões no backend, proteção de informações pessoais e acesso restrito aos documentos.
